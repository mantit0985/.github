# Context: .github Hub

This repository is the central configuration, governance, and automation hub for the mantit0985 GitHub account.

## Goals
- Maintain a high-signal, minimalist public profile.
- Provide reusable workflows and templates for all satellite repositories.
- Automate account health auditing and profile updates via the RQE loop.

## Architecture
- `.github/`: Centralized workflows, actions, and templates.
- `profile/`: Data for the GitHub profile README.
- `docs/`: Standards and guidelines for the entire account.
