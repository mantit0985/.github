# Security Policy

## Vulnerability Disclosure

We take the security of our projects seriously. If you discover a security vulnerability, please report it responsibly.

### Reporting Process

To report a security issue:
1. **Do not** open a public issue.
2. Submit a detailed report via the GitHub **Report a vulnerability** feature or contact the maintainer directly.
3. Include:
   - A description of the vulnerability.
   - Step-by-step instructions to reproduce the issue.
   - Potential impact.

### Our Commitment

- **Acknowledgement**: We will acknowledge receipt of your report within 48 hours.
- **Resolution**: We aim to provide a fix or mitigation as quickly as possible.
- **Disclosure**: We follow coordinated disclosure. We will not disclose the vulnerability publicly until a patch is available or a reasonable amount of time has passed.
