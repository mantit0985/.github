### 🥯 The Bio (or: Why I'm Like This)
I am a **professional code breaker** and a **dedicated tinkerer** who lives in the sweet spot between *"this should never happen"* and *"I wonder what happens if I delete this line."* 

My approach to software engineering is simple: if it doesn't break on the first run, I didn't try hard enough. When I'm not accidentally triggering recursive loops that threaten local network stability, you can find me debating the optimal surface-area-to-cheese ratio of a gourmet grilled cheese.

**Core Philosophy:** If the bug is a feature, the crash is just an unplanned nap.
